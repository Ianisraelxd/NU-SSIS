## Flow

| # | Step | Time | Notes / decisions |
| --- | --- | --- | --- |
| 1 | **Project introduction** — review the problem, users, objectives, proposed system | 5–10 min | |
| 2 | **Assign Scrum roles** — Product Owner, Scrum Master, Developers (+ front-end, back-end, database, UI/UX, testing/docs) | 5 min | |
| 3 | **Review the Product Backlog** — add, remove, clarify features (remember: services, **no LMS**) | 15–20 min | |
| 4 | **Prioritise the backlog** — High / Medium / Low | 10 min | |
| 5 | **Plan Sprint 1** — only what you realistically expect to finish | 15–20 min | |
| 6 | **Set the Sprint Goal** | 5 min | Proposed: see `05-sprint-plan.md` |
| 7 | **Assign tasks** | 10 min | |
| 8 | **Agree on the Scrum schedule** — sprint length, Daily Scrum, Review, Retrospective, next Planning | — | |
